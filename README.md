# 🎮 LootBox Simulator BETA

My first Python project!

LootBox Simulator is a terminal-based game featuring:

- 🎲 Random loot drops
- 💎 Four rarity levels: Common, Rare, Legendary and Mythic
- 🎒 Inventory management
- 💰 Coin economy
- 🛒 Weapon selling system
- ☠️ Game Over screen

## 🛠️ Built With
- Python
- PyCharm
