# 🎮 LootBox Simulator BETA

My first Python project!

LootBox Simulator is a terminal-based loot game built with Python. Open chests, collect rare items, manage your inventory, earn coins, upgrade your abilities and progress through player levels!

## ✨ Features

- 🎲 Random loot generation
- 💎 Four rarity levels: Common, Rare, Legendary and Mythic
- 🎒 Inventory management
- 💰 Coin economy
- 🛒 Item selling system
- 📊 Player statistics
- ⭐ XP and player leveling system
- 🏪 Upgrade Shop
- 🍀 Lucky Charm — increases rare loot chances
- ⭐ XP Booster — increases XP earned per chest
- 💰 Coin Multiplier — increases selling profits
- 🎟️ Chest Discount — reduces chest opening costs
- ☠️ Game Over screen
- 🎨 Colored terminal interface

## 🛠️ Built With

- Python
- PyCharm
